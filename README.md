# 動画リサイズ

動画をえらぶだけで、ぐっと小さくするアプリ。
小さくした動画は、そのまま **LINE などで送る**か、**保存**できる。
動画はスマホ(ブラウザ)の中だけで処理し、どこにも送らない。

**使う: https://roguepink.github.io/dogaresize/**

## 使い方

1. どのくらい軽くするか、割合でえらぶ(**25%** = 重さを4分の1に、が標準。50% / 10% も)
2. 「動画をえらぶ」→ 動画を1本えらぶ → 長さ・できあがりの重さの見込みが出る
3. 「小さくする」→ **動画と同じ時間がかかる**(1分の動画なら 約1分)。終わるまで画面をそのままに
4. できあがったら「LINEなどで送る」(送り先を選ぶ画面が出る)か「保存する」

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ使える
- **LINE の中で開いたときは うまく動かないことがあり、ホーム画面にも入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選ぶ
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても使える

## 中身・しくみ

- `index.html` 1枚で完結(外部ライブラリなし)。`manifest.webmanifest` と `sw.js` でホーム画面・オフライン対応
- しくみ: 動画を再生しながら、小さい絵(canvas)に描き直して `MediaRecorder` で録画し直す。だから **動画と同じ時間がかかる**(ブラウザだけで、ライブラリなしに動画を作り直せる唯一の方法)
- できあがりの形式はブラウザしだい: iPhone の Safari は **mp4**、Android の Chrome は たいてい **webm**(`CONFIG.MIMES` の順に、作れるものを使う)
- ほかのアプリに切り替えると いったん止まり、戻ると続きから(切り替え中は絵が止まってしまうため)。画面が消えないように wake lock も使う
- 割合(`CONFIG.MODES` の `pct`)から、もとの動画の 1秒あたりのデータ量 × 割合 を目標にする(`plan()`)。絵の大きさ(1080 / 720 / 480 / 360)は「1画素あたりのデータ量が足りる いちばん大きいもの」を自動で選ぶ。音は 96kbps 固定(64k だと mp4 の音の圧縮が失敗した)
- 割合を 75% などに変えたい・増やしたいときは、`CONFIG.MODES` と、同じ `data-mode` のボタン(HTML)を直す
- ブラウザの圧縮は「目標まで」しか使わないので、単純な絵の動画は見込みより軽くなる(スマホで撮った動画は見込みに近い)
- アドレスの末尾に `#play` をつけると、その場で作った3秒の動画で動作確認できる(自動再生を許したブラウザでのみ)

## 確認したこと・していないこと(2026-10-12)

- Mac の Chrome で、横(1920×1080)・縦(1080×1920)の mp4 を小さくして、mp4 ができ、再生できることを確認
- **実機(iPhone の Safari・Android の Chrome)と LINE の共有は未確認**

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)や `manifest.webmanifest` を変えたときだけ
- Chrome が「すでにインストールされています」と言って入れられないときは、`manifest.webmanifest` の `id` を新しい値に変える
