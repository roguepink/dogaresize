# 動画リサイズ(→ 写真・動画リサイズ にまとめました)

2026-10-13 に、写真リサイズ(`roguepink/resize`)と1つにまとめました。

**使う: https://roguepink.github.io/resize/**(上の「🎬 動画」を押す)

このアドレス(`roguepink.github.io/dogaresize/`)を開くと、自動で そちらの動画の方へ移動します。
前にホーム画面に入れた人は、開いたときに古い版が消えて、新しいアドレスへ移ります(新しい方をホーム画面に入れ直してください)。

アプリの中身・直し方は `roguepink/resize` の README を見てください。
